O que é HTML

HTML é uma linguagem de marcação feita para aplicações em SOFTWARE onde ela marca textos,dar significados as aplicaçõesHTML é uma linguagem de marcação utilizada para estruturar e dar significado ao conteúdo de páginas Web, como títulos, parágrafos, links, imagens e formulários

a diferença entre HTML e C

HTML é feita para aplicações para inserir textos,fotos e dar significado a isso, C ja é uma linguagem de programação com funções,laços de repetições e etcHTML estrutura o conteúdo de uma página. C é uma linguagem de programação capaz de executar instruções, cálculos, decisões, repetições e funções!
